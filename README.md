# Генератор Коммерческих Предложений

Автоматизированная программа для создания коммерческих предложений на климатическую технику (кондиционеры, вентиляция и др.).

## Возможности

- Импорт данных из Excel и PDF
- Автоматическое распознавание брендов и моделей
- Генерация DOCX и PDF коммерческих предложений
- База клиентов и история КП
- Редактор брендовых профилей и синонимов
- Удобный современный интерфейс на CustomTkinter
